# level_player
The game. Open `index.html`. 300 levels, 27 languages, synthesized sound effects (3 styles), built-in ambient background sounds, and optional audio files of your own.
- Settings > Language: English + 13 Indian languages (Hindi, Bengali, Telugu, Tamil, Marathi, Gujarati, Kannada, Malayalam, Punjabi, Odia, Assamese, Urdu, Nepali) + 13 world languages. Add more by adding a line in `i18n.js`; missing text falls back to English.
- Islamic audio: see `audio/README.md` (you add the files, then list them in `audio/tracks.js`).
- Settings > Load levels.json plays levels exported from level_creator.
