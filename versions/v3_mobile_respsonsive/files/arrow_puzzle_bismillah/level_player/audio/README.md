# Islamic background audio (you add the files)

The game cannot ship recitations or nasheeds for you: audio has to come from a source you have checked and have the right to use.

1. Get the file (mp3/ogg/m4a) from a source you trust. Examples to check: quran.com, everyayah.com, quranicaudio.com. Read each site's terms before using audio in an app.
2. Prefer: a well-known reciter (correct tajweed), vocals-only nasheed (no instruments), or dhikr.
3. Copy it into this `audio/` folder and add one line to `tracks.js` (see the example inside).
4. Reload the game: it appears under Settings > Music, grouped by category.

Good practice: keep Quran recitation off by default, never attach it to taps/effects, and let the player stop it at any time. Ask your imam or a scholar if you are unsure about using recitation as game background; vocals-only nasheed or dhikr are the usual safer choice.
